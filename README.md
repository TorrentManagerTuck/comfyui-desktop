# ComfyUI Desktop

### The official ComfyUI desktop application

ComfyUI Desktop is the official packaged version of ComfyUI — the most powerful node-based Stable Diffusion interface. Run Flux, SDXL, and any diffusion model with a clean, auto-updating desktop experience.

<br>

---

## Features

| | |
|:---|:---|
| **Node Graph** | Build and share complex generation pipelines with a visual editor |
| **Auto Updates** | Built-in updater keeps ComfyUI and your Python environment current |
| **Model Manager** | Browse, download, and organize models directly from the app |
| **Community Nodes** | Access thousands of community custom nodes with one-click install |
